# Historical TypeTide materials

ARType preserves the TypeTide MIT license and upstream attribution. The following
materials document the original product and are retained as historical references:

- `docs/index.html`, `docs/blog/`, their images and the upstream website checklist;
- root translated TypeTide READMEs and any upstream branding/download references;
- `docs/archive/upstream/windows-README.md` and `windows-TESTING.md`.

Their offline models, Ollama/direct API configuration, public GitHub updates,
TypeTide installers and older release procedures are not ARType product claims
or current deployment instructions. Current entry points are the root `README.md`,
`docs/OPERATIONS.md`, `docs/ACCEPTANCE.md` and `windows/README.md`.

Obsolete runtime-download and direct-provider E2E scripts were removed from the
active Windows scripts directory. Git history retains their implementation.
The old platform build entry points forward to the corporate build scripts.
The old macOS convenience command no longer changes versions, commits or pushes.
