# Приёмка поставки ARType

Проверяйте на конкретном commit и окружении. Исходники, CI или DMG сами по себе
не доказывают готовность к раздаче сотрудникам.

## Программная проверка

- [ ] Только администратор платформы выдаёт глобальные права; отзыв действует
      в существующей сессии. Владелец/администратор организации не повышает себя.
- [ ] Бесплатный владелец не переводит до подключения платного места.
- [ ] Цена/кредиты доступны только платформе; корректировки и повторы запросов
      не перезаписывают журнал и не начисляют сумму повторно.
- [ ] Списание уникально по tenant/email/месяцу; повторное включение бесплатно,
      другой tenant платный. Продление целиком ожидает достаточного баланса.
- [ ] Отключённые места не продлеваются; смена цены не меняет старые списания.
- [ ] В программе на старте видна причина неоплаченного доступа; API не даёт
      выполнить перевод в обход клиентского уведомления.
- [ ] Dashboard открывает настройки организации с заполненными подключениями.
- [ ] DMG/EXE скачиваются после входа, SHA-256 совпадает; посторонние файлы
      каталога releases недоступны. Пилотные пакеты явно обозначены.

- [ ] PostgreSQL: роли/изоляция, гонки мест и квот, истечение приглашений,
      блокировка, CSRF, state/nonce, параллельный первый вход, device tokens.
- [ ] AI-ключ сохраняет только оператор; ключ не возвращается API, хранится
      зашифрованным, остаётся после перезапуска, замена действует без рестарта.
      Ошибка расшифровки не вызывает provider request и не резервирует usage.
- [ ] HTTP provider: ошибки, redirects, обрыв, незавершённый finish_reason.
- [ ] Кабинет: запоздавший ответ не подменяет форму другой организации.
- [ ] Mac: unit и E2E; смена организации/выход не применяют старый перевод.
- [ ] Windows: MSVC build, самотесты, installer build.
- [ ] Docker: healthy API/база и сохранение данных после перезапуска.
- [ ] Backup восстанавливается в отдельную базу с теми же организациями.
- [ ] Docker setup импортирует Google JSON в приватный `.env`, не печатает
      секреты и не перезаписывает существующую конфигурацию. Локальный Compose
      публикует только loopback API; backup/restore работает без Caddy.

## Рабочий сервер

- [ ] Конечные DNS/TLS, API и PostgreSQL закрыты извне.
- [ ] Настоящий Google Web OAuth: оператор, приглашённый и неприглашённый email.
- [ ] Две организации: каждый сотрудник видит только свою.
- [ ] Реальная AI-модель переводит; ключ отсутствует в клиентском пакете.
- [ ] Смена модели/правил влияет на следующий перевод без переустановки.
- [ ] Отключение сотрудника/организации останавливает следующий запрос.
- [ ] Лимиты/ошибки не заменяют исходный текст; CSV совпадает с операциями.
- [ ] База/логи не содержат текстов. Нагрузочный тест соответствует пилоту.

## Чистые установки

- [ ] Mac Apple Silicon/macOS 26+: Developer ID, notarization, Gatekeeper,
      установка в Applications, ручной Accessibility, автозапуск/выход.
- [ ] Windows 10/11 x64: подписи EXE/инсталлятора, установка/удаление/автозапуск.
- [ ] Пакеты содержат конечный HTTPS URL, ARType и полный MIT notice.
- [ ] Вход из обоих клиентов открывает браузер, код совпадает, сессия сохраняется
      при перезапуске, выход отзывает её, смена организации отменяет старую работу.
- [ ] Перевод и замена проверены в редакторе, браузере, целевом мессенджере;
      clipboard восстановлен, отмена замены работает.
- [ ] Проверены недоступная сеть/сервер/провайдер и истёкшая сессия.

Раздачу сотрудникам можно считать готовой после рабочей инфраструктуры,
подписанных пакетов и чистых установок на обеих платформах.
