# Эксплуатация ARType

Оператор (ADMIN_EMAILS) управляет всеми организациями, доступом, местами,
моделью, aliases и лимитами. Владелец управляет всеми ролями своей команды,
языками и инструкциями; администратор — рядовыми участниками, языками и
инструкциями. Участник использует клиент. Google-вход без приглашения не даёт
доступа к организациям.

Последнего действующего владельца отключить нельзя: другой владелец сначала
должен принять приглашение входом. Истёкшее приглашение можно возобновить,
отключив запись и выбрав «Пригласить снова». Приглашения резервируют места 7 дней.

Приостановка организации или отключение участника останавливает следующий
перевод. Уже отправленный провайдеру запрос может завершиться и быть учтён.
Клиент не повторяет оплачиваемые запросы автоматически и не использует кеш.
Месячная квота учитывает успешные переводы и резервы выполняющихся операций;
ошибки освобождают резерв. Частота включает неудачные принятые попытки.
Одновременно разрешены не более двух запросов сотрудника, плюс общий лимит
организации. Учёт и CSV используют UTC, календарный месяц.

```bash
docker compose ps
docker compose logs --tail=100 api web
```

`/health` проверяет API/базу; реальный Google и AI требуют отдельного входа и
перевода. Провайдер ограничен 45 секундами. Его квоты остаются внешним лимитом.
За Caddy включён TRUST_PROXY=1; порт API должен оставаться закрытым извне.
Валидные устройства имеют отдельные лимиты polling, в том числе за офисным NAT.

Производительность на целевом сервере ещё не измерена. Перед массовой выдачей
проверьте ожидаемые параллельность/длину текстов. Атомарные PostgreSQL-резервы
работают между API-репликами; анонимный ограничитель входа хранится в памяти
процесса и при масштабировании дополняется ограничителем входного трафика.

## Копии и восстановление

```bash
deployment/backup.sh /srv/backups/artype
deployment/restore.sh /srv/backups/artype/backup.dump --replace-database
```

Восстановление заменяет базу, останавливает API/web на время операции.
В локальном режиме без Caddy останавливается только API; после восстановления
возобновляются только сервисы, которые работали до него. Compose-режим берётся
из `COMPOSE_FILE` в `.env`, поэтому backup/restore одинаковы для обоих режимов.
Проверяйте восстановление на отдельной инсталляции. Дамп содержит email,
memberships и хеши сессий — ограничьте права, храните копию вне этого сервера.
Отдельно защищённо сохраните `.env` и доступы Google/подписи.

## Обновление и хранение

Сохраните дамп, обновите исходники до проверенного commit/tag, выполните
`docker compose up -d --build`. Начальная схема отмечена в schema_versions;
изменения требуют отдельных миграций. Не откатывайте несовместимую схему без
подходящего дампа. Смена модели/инструкций не требует нового клиента; смена
домена требует пересборки и нового Google redirect URI.

Google secret и AI-ключи остаются в окружении API. После изменения `.env`
пересоздайте API. Сессии действуют 7 дней в браузере и 30 дней на устройстве;
после истечения нужен новый вход. Просроченные сессии, OAuth states и pairing
очищаются автоматически. Usage/audit хранятся без текстов; автоматического
удаления старой технической статистики в v1 нет, срок определяет оператор.
