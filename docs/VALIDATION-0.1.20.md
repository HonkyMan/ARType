## Существенные изменения

- Сервер разделён на HTTP, авторизацию, организации, биллинг, подключения,
  провайдера и версионные миграции; циклические зависимости устранены.
- Кабинет отклоняет устаревшие ответы после навигации/выхода. Финансовый журнал
  сохраняет запрос и idempotency key до отправки, переживает reload той же вкладки
  и сохраняет ключ при ошибке повторной попытки после неизвестного результата.
- Замена текста привязана к исходному полю и выделению; сомнительный результат
  остаётся для ручного копирования. Clipboard восстанавливается только пока
  приложение владеет своей временной записью.
- Ответы ограничены по размеру, JSON/SSE проверяются полностью; неполные данные
  и NUL отклоняются до Copy/Replace.
- Windows использует управляемые workers и очередь сообщений. Автоматические
  дампы памяти заменены JSON с ограниченным набором числовых метаданных.
- macOS Services показывает результат в отдельном popup, проверяет enabled и
  исключения приложений; поздней записи в pasteboard вызывающей программы нет.
- Старые локальные модели, direct-provider paths и upstream updater удалены.
  Полная MIT-лицензия TypeTide сохранена в обоих установщиках.

## Перед массовой раздачей

1. Купить домен, развернуть Docker с HTTPS и добавить новый Google callback.
2. Пересобрать клиенты под этот адрес, подписать Windows и выполнить
   Developer ID/notarization для macOS.
3. Проверить чистую установку и настоящий вход, Accessibility/UIA, Services,
   clipboard/Undo, автозапуск и завершение во время сетевого запроса в целевых
   редакторах и мессенджерах. Автоматизированные тесты не заменяют эту проверку ОС.

Текущие DMG/EXE явно обозначены `UNSIGNED-VALIDATION` и настроены на
`http://127.0.0.1:8080`. Они предназначены для локальной проверки на компьютере,
где доступен сервер по этому адресу. macOS: Apple Silicon, macOS 26+;
Windows: x64. Это не установщики для удалённых сотрудников с готовым публичным API.

После обновления клиента нужен один повторный вход Google: старый токен не
имеет доказанного origin. Его запись не читается, не переносится и не удаляется.
Настройки организации, языков и shortcuts сохраняются. Старые Windows `.dmp`
также не удаляются автоматически.

WinHTTP отменяется между синхронными вызовами, поэтому нет обещания мгновенного
прерывания зависшего вызова или строгого wall-clock лимита. Проверка фокуса
и отправка клавиатурного события ОС не атомарны. SessionStorage-журнал не
переживает закрытие вкладки и не синхронизируется между устройствами;
PostgreSQL остаётся источником финансовой истории.
