# ARType 0.1.21 — проверка изменений кабинета и языков

Дата: 20 октября 2026. Код приложения: `880f5c29e192f4f702c9e47e56d3c3c1c91eeaf6`.
Последующий коммит добавляет отчёт и включает ролевую политику в архивы поставки.

## Изменения

- AI-провайдеры: таблица, отдельные страницы создания и редактирования,
  сохранение, отмена, адреса страниц, восстановление после reload и Back.
  Пустой ключ при редактировании сохраняет существующий. Смена адреса требует
  нового ввода ключа. Создание с занятым именем возвращает 409, в том числе
  при параллельных запросах.
- Удалены метрики со страницы рабочих пространств.
- Языки выбираются флажками с названиями. Для новых организаций включены
  русский, английский, бенгальский, хинди и китайский. Ограничения существующих
  организаций автоматически не переписываются.
- В локальной Backoffice отдельно разрешены `bn`, `hi`, `zh` через доменную
  операцию с аудитом. Проверено сохранение пользователей, членств, балансов,
  финансовых операций и зашифрованного ключа.
- Права существующих ролей описаны в [ROLES.md](ROLES.md); полномочия не менялись.

## Внешние ограничения

Реальный OpenRouter вернул **401 — API key expired** для сохранённого подключения
Backoffice. Пользователю предложено заменить ключ в редакторе AI-подключения.
Успешные ответы реальной модели на трёх языках в этом прогоне не подтверждены.
Тесты серверного пути используют имитацию провайдера; они не оценивают качество
машинного перевода.

Установщики предназначены для проверки с `http://127.0.0.1:8080` и не имеют
сертификатов публичной подписи. Для внешней раздачи по-прежнему нужны публичный
HTTPS-адрес, соответствующий Google callback, пересборка клиентов и проверка
установки на рабочих компьютерах.
